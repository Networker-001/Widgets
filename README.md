## Installation

### FrSky Ethos
1. Lade den gewünschten Widget-Ordner aus dem Verzeichnis `ethos/` herunter.
2. Kopiere den Ordner auf die SD-Karte des Senders in das Verzeichnis `/scripts/`.
3. Starte den Sender neu oder lade die Lua-Skripte neu.

### RadioMaster TX16S
1. Lade den gewünschten Widget-Ordner aus dem Verzeichnis `radiomaster-tx16s/` herunter.
2. Kopiere den Ordner auf die SD-Karte der TX16S in das Verzeichnis `/WIDGETS/`.
3. Wähle das Widget auf dem Startbildschirm über die Bildschirmkonfiguration (*Telemetrie / Widgets*) aus.
